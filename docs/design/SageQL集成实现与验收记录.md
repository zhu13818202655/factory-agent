业务接口见 [L2 自主分析契约](../api/L2自主分析契约.md)。

## 实现范围

SageQL 仓库提供轻量、独立的 `sageql-core` wheel 与原 SQL Agent 兼容层。factory-agent
通过 wheel 注入模型、授权数据 Provider、批准知识、结构化计算、观察策略与进度适配；
L2 沿用同一会话执行器、缓存、只读 DuckDB、卡片和产物提交。源码目录不是运行依赖。

V2 两族事实使用当前问题窗口和已有授权。床号按原始字符串精确匹配，保留前导零；
报工量为件·工序，进度发卡与实收为件，实收是查询时累计值。任何实际缩小的查询窗口、
计算条件及配置使用状态均由已验证的结果元数据回显。

V1 基础字典与配置安全投影按需求方确认适用于当前租户的所有角色；事实与工资仍按现有权限。
目录沿用 24 小时缓存，不包含单价、身份、基础设施秘密及备注。制单配置必须先从本轮获准
进度取得真实实体，款号表单按已验证款号实体调用；缺少稳定键不猜测关系。

共享预算累计初始解析、权限模型调用、规划、修复、上游尝试、分页、载入与扫描。
整个交互至多一次语义修复。L2 冷态只取当前窗口，不临时触发全厂年度快照；已有完整快照
可以复用。shadow 仍计实时请求，异常或不一致使用验证的实时视图并失效缓存。

## 工程验证

- core：真实安装 wheel 后 31 项通过；原 SQL Agent、SQLite、权限和 workflow 兼容回归 50 项通过。
- core 独立目录隔离导入、wheel 清单、MIT、`py.typed`、仅 Pydantic 依赖及版本检查通过。
- core Python 3.9 语法与严格类型检查通过；运行测试使用 Python 3.12.14。
- 宿主包含真实 Agent 的观察驱动规划、两次 DuckDB 计算、多结果引用提交、安全观察、
  句柄复用、字典知识零事实读取、shadow、必需字段、稳定键与基数、权限、预算、取消和超时测试。
- 取消保留已提交终态，超时按既有超时终态收束；事件适配复用 `interaction.progress`，
  回调失败不改变业务答案，不记录异常内容。

最终全仓库回归：**2088 通过、49 跳过、0 失败**。跳过均为未显式配置的可丢弃 PostgreSQL
或 S3 测试依赖。3 条警告来自既有 LiteLLM 测试日志 worker 与 FastAPI 弃用状态码提示。
Ruff 检查与格式、严格 Pyright、Bandit 静态安全扫描、uv 锁一致性及 Git diff 空白检查通过。
`pip-audit --skip-editable` 完成，已安装依赖未发现已知漏洞。
Windows 使用与 Makefile 相同的工具直接执行检查；未执行 Linux shell 脚本语法和 Docker 镜像运行检查。

完整回归后额外补充目录可选排序字段与整数排序回归，宿主测试 21 项通过；
不把无来源或未完成分析计为“整个问题由缓存完整覆盖”。
最终宿主、会话、模型预算、事实取数及安全组合复核 **84 项通过**；随后严格 Pyright 为 0 错误，
Ruff 检查通过，355 个项目 Python 文件格式符合规范。

## 获准测试环境只读验证

使用需求方确认的 `.env` 测试环境凭证。验证只通过 `data_api` 请求已登记读取接口，
先完成身份及权限校验；输出仅含逻辑集合、完整性、行数、类型与安全失败类别，不输出客户
记录、实体编号、姓名、原始响应、地址或凭据。不调用模型，不写数据库、缓存、产物或导出。

| 逻辑集合 | 已完成的实测证据 |
| --- | --- |
| `styles` | 完整，1399 条；同一响应的款号类型集合通过命名集合验证 |
| `production_types` | 完整，4 条 |
| `processes` | 完整，2015 条 |
| `style_colors` | 经验证款号实体的完整配置，5 条 |
| `style_sizes` | 同一实体的完整配置，6 条 |
| `hanging_lines` | 完整真实空集，0 条 |
| `reported_production` | 2026-09-01 一日窗口，完整，18 条 |
| `production_progress` | 2026-09-01 一日窗口，完整真实空集，0 条 |

名称、单位等允许为空的展示元数据按未提供处理；稳定实体编号仍严格校验，
整型 JSON 编号可规范为字符串，原字符串编号保留前导零，拒绝小数、不精确数值与非有限值。

款号工序配置与后续制单进度验证遇到接口超时。制单工序缺少已验证的非空制单实体，
独立款号类型读取也存在超时。因此完整款号工序、非空进度、制单工序及其真实跨接口关系
仍为未验证；超时不被记录为空集，类型/配置的合成测试通过不替代这些实测。

验证工具为 `python -m factory_agent.source_verification --test-environment --date YYYY-MM-DD`，
可用 `--dataset` 限定逻辑集合。总时长、请求数、行数及单次传输均有独立上限。

## 未完成的客户验收边界

逐组客户服务端动态分组等价、各真实角色数据范围、缓存冷热收益分布、容量性能、
身份变化与暂停租户在真实基础设施上的端到端验收仍需独立获准测试条件。

继续使用明确限制，不输出猜测数值。

数据库与对象存储集成测试只连接显式配置的可丢弃测试实例，当前缺少这些配置的用例按
仓库规则跳过。未执行迁移、发布、客户环境变更或部署。
